# KLWP Home Screen

My KLWP home screen.

https://github.com/user-attachments/assets/bfec5e25-8650-4a8e-b46b-a30cccdc1351

Requires Tasker to forward commands to PowerAMP, etc. There is also nova launcher preset configured for
this home screen, but you can use whatever.

KLWP: [wallpaper](configs/Miku.klwp?raw=1)  
Tasker: [project](configs/PA.prj.xml?raw=1)  
Nova Launcher: [backup](configs/2026-11-14_18-36.novabackup?raw=1)

It also acts as a client for [rust-notifier](https://github.com/funmaker/rust-notifier), change
the `url` global KLWP value to point it to your instance. It could probably be tweaked to work
with any rss feed.
